No ?token= in the URL. Get one via curl:
curl -X POST http://localhost:3000/auth/register -H "Content-Type: application/json" -d '{"email":"you@example.test","password":"whatever12345"}'
curl -X POST http://localhost:3000/auth/login -H "Content-Type: application/json" -d '{"email":"you@example.test","password":"whatever12345"}'
then append &token=<accessToken from login> to this page's URL.

No ?doc= in the URL, or join was rejected as forbidden. Since SCRUM-41, joining requires a real doc you own or collaborate on — create one first (using the token from above):
curl -X POST http://localhost:3000/docs -H "Authorization: Bearer <accessToken>" -H "Content-Type: application/json" -d '{"title":"Test doc"}'
then append &doc=<id from the response> to this page's URL.
